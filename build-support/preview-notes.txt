Stardot · 星点 1.0.0

支持 Windows 11 x64，无需安装 Python 或 uv。
安装前请先从托盘退出正在运行的旧版 Stardot。

已提供：桌面星星、拖入文字、概要与日期识别、清单编辑、完成与归档、删除撤销、任务日历、提醒、全局复制录入、位置记忆、备份与恢复。

单击星星打开清单；Ctrl + Enter 保存；双击编辑区切换原文。
复制文字后按 Ctrl + Alt + S 录入；Ctrl + Alt + Space 找回星星。
清单右侧的小日历进入任务日历，设置图标打开快捷键与备份设置。
快捷键冲突时请在设置中更换组合。

有具体日期和时刻的新任务默认提前 10 分钟提醒；点铃铛可改为准时、30 分钟或关闭。没有具体时刻不提醒。
旧版任务升级后仍保持无提醒状态，可逐项点击铃铛开启。
请保持星点在托盘运行。睡眠或重新启动后合并补提醒；完全退出时不发送通知，系统勿扰可能隐藏通知。
清单或日历的 × 只收起窗口；退出请右键托盘选择退出，或在应用内按 Ctrl + Q。

任务保存在 %LOCALAPPDATA%\Stardot\stardot.sqlite3。
覆盖安装、卸载均保留用户数据。升级前自动备份旧数据库；请通过设置中的导出备份保留独立副本。
恢复备份会替换当前任务，确认前展示任务数量，并自动保留恢复前备份。备份包括任务与提醒记录，不包含窗口位置、快捷键设置。
当前不包含手机同步、自动更新及代码签名。Edge/微信中无法拖出的文字可用复制快捷键录入。
